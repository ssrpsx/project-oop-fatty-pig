# 🐷 Fatty Pig Game

**Fatty Pig Game** is a 2D single-player game inspired by *Flappy Bird*.  
The player controls a pig that must fly through gaps between pairs of pipes (top and bottom) moving from right to left.  
Each successful pass through a pipe increases the score.

The game ends when the pig collides with a pipe or falls to the ground.  
After a game over, the player can restart the game immediately.

---

## 🎮 Gameplay

- Press **Spacebar** to make the pig fly upward  
- Control the timing carefully to avoid obstacles  
- Try to achieve the highest score possible  

---

## 🥕 Carrot & Skin System

- Carrots appear during gameplay  
- When the player collects a carrot, the game **randomly assigns a pig skin**

### ✨ Special Effect
- If the **pig skin matches the current map skin**:
  - The pig becomes **2 times smaller**
  - This makes the game **easier to play** by improving maneuverability

---

## 🌍 Maps & Skins

The game includes **3 different themes**:
1. Green Grass Theme  
2. Desert Theme  
3. Space Theme  

Each theme affects both the map and available pig skins.

---

## ⭐ Features

- 2D single-player arcade gameplay  
- Score tracking system  
- Random pig skin system via carrot collection  
- Special size-reduction mechanic for matching skins  
- 3 unique maps and visual themes  
- Simple and responsive controls  
- Restartable gameplay after game over
